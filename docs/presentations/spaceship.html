Game · shipping today

Spaceship

A vertical “dodge the falling stars” arcade game on the STM32F411 — move an amber block in X and Y to weave through obstacles while the pace ramps up.

What it is

A single-screen reflex game with three states — attract → playing → game-over — driven entirely from one bare-metal main loop. Obstacles are spawned as nodes in a singly-linked list, fall each frame, and recycle to the top; an AABB hit test against the player ends the run.

How it works

  • Analog joystick on the ADC steers the 5×5 player block.
  • Stars spawn ~1 in 10 ticks and accelerate as a difficulty timer winds down.
  • Everything is drawn straight over SPI to a hand-written ST7735 driver.
128×160 ST7735 · exact RGB565 colours · open live ›

Skills demonstrated

Bare-metal ST7735 driver (datasheet command sequences) SPI master @8 MHz, mode 0, MSB-first Software CS/DC bit-bang protocol RGB565 framebuffer colour Finite state machine Dynamic linked-list obstacles (malloc/free) 12-bit ADC dual-channel scan sampling 8-sample averaging + deadzone + hand calibration AABB collision detection HAL_GetTick timing & difficulty ramp Retargeted printf-over-UART debug

Shipping today — MVP

  • Playable dodge loop with attract / play / game-over states
  • Dynamic obstacle field via linked list
  • Analog joystick control with filtering
  • Live on-screen score & restart

Where it’s headed — Full release

  • Score = dodges (today it counts survival ticks)
  • Bounded difficulty curve (no run-away pacing)
  • Obstacle lifecycle — recycle nodes, zero heap growth
  • Seeded RNG for a fresh field each power-up
  • DMA + framebuffer render (kill the flicker)
  • Exit-to-shell as a console cartridge

Proof-of-concept framing

The headline gap — the score counts frames survived, not dodges — is the clearest “next story.” It is a deliberate MVP shortcut: the loop, rendering, and input are proven, and swapping a survival counter for a dodge counter is a small, well-scoped change that was always planned. Same story for the unbounded obstacle list and the unseeded RNG.
