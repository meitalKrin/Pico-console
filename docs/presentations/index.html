How to read these

The two existing games are deliberate MVP proofs-of-concept. Where a core-loop gap shows (no game-exit yet, score counts survival ticks, copy-pasted drivers), it is framed as the next planned story — the gaps trace the roadmap from “three separate firmwares” to “one console.”

Deeper docs: Console PRD · Console Architecture · Interview Brief · Cross-cutting bugs. Per-game PRD / Architecture / Strengths / Bugs live in the spaceShipGame and EmbeddedPaint repos.
